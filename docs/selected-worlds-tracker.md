## Progress updates

Use these statuses as work proceeds: **Selected → Inspecting → Planned → Building → Testing → PC ready**. Record owner review and any requested device or live-server delivery separately from technical readiness. Link each row to its maintained implementation plan and actual evidence; do not mark a world complete from code or extracted assets alone.

For each world, the linked plan should track:

- Recovered scene and asset identities, mechanics, eligible characters, action animations, hand and object contact, audio and finish reactions.
- Every activity listed above, including replay, interruptions and smaller interactions found during recovery.
- Four-player shared participation and progress, NPC assistance where appropriate, and independent departures that preserve siblings' play.
- Saves, reopening, reconnecting and separation of private offline progress from the authoritative shared world.
- Explicit family adaptations, actual validation, remaining limits and the playable launcher or requested delivery.
