## Open and play the current prototype

1. Open `Unity/FamilyPlayset` in Unity **6000.3.24f1**.
2. Choose **Little Weeps > Sandcastle > Open isolated visual prototype**, or open `Assets/FamilyPlayset/Scenes/SandcastleVisualPrototype.unity`. Press Play.
3. Set Game View to **1024x768** (tablet) or **1280x591** (phone). The labelled14-piece example is a disposable fixture constructed through current authority commands, never a required player arrangement.
4. Open the small **Preview** panel and choose **Empty pit**. It also contains Example castle and Full16pieces. All three replace only the in-memory synthetic family.
5. **Build**: choose a pictured mould, tap sand, then Confirm; Rotate/Cancel remain visible. Scoop three times, Water and Tip. Water may come first. Underfilled Tip retains progress; a full dry bucket needs Water and Tip, without extra scoops.
6. Continue choosing shapes. Tap a visible piece face to select it; **Decorate** exposes Flag/Shell/Pebble/Door/Window. Independent sockets allow combinations; occupied/full sockets disable the corresponding controls. Build returns to construction. Help and Leave stay accessible.

Fresh runnable artifact: `Builds/SandcastlePrototype/P9/SandcastlePrototype.exe`, release, only this scene. Rebuild through `LittleWeeps.EditorTools.SandcastlePrototypeBuild.Build` with `-prototypeOutput` pointing to a new unused executable path. No app installation or server bootstrap is needed.
