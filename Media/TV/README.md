# Personal TV video library

Place the family's TV videos in this folder:

`C:\Users\sephi\Desktop\Little weeps game\Media\TV`

The root `.gitignore` excludes everything here except this README, including all
video formats, nested folders, thumbnails, subtitles, local catalogs and temporary
conversion files. These files stay on this computer and are not part of the
private GitHub repository. Back them up separately when needed.

This is the reserved source folder for the planned TV importer. Adding videos here
does not yet add them to the game; the thumbnail library and import workflow are
still pending under TV-01. The generated foundation test clip in Unity is separate
and remains tracked so its playback checks can be reproduced.

Do not force-add personal media to Git or move it into a tracked Unity asset folder.
