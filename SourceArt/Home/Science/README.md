# Layered Home science artwork

`marble-ramps.png` is the selected transparent atlas from the built-in imagegen tool. `marble-ramps.manifest.json` preserves both exact prompts and original/edited output paths. The runtime RGBA file is an unchanged copy. `SoloMarbleRamps.cs` owns inspected sprite crops, including the basket rear crop that excludes the separately drawn foreground wall.

Board, three material tracks, basket rear/front, marble, knob and stop are independent components. Ramp endpoints and surface selection use the saved course; the pictured ball follows the same trajectory as the authority. Generated art is not physical user acceptance.
