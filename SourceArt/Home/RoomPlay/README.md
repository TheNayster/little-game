# Room play art

Three imagegen cutouts: a layered blanket nest, reusable toy teapot and cup. Originals are copied unchanged into Resources/RoomPlay; runtime front polygons mask the lower tucked-in plush. One shared texture per sprite, 512-pixel import cap, no mipmaps or Read/Write. Exact subject prompts, reference and hashes are in manifest.json.

Shared prompt suffix: Match the existing clean flat family dollhouse art, softly colored brown outlines, crisp pastel fill shapes, restrained two-tone shading, no haze outside the outline, transparent alpha, no text, painted checkerboard, photorealism or 3D.
