# Riding drawing sources

Generated September 30 with built-in image_gen, using the already selected Bluey/Bingo action sheets and the vehicle atlas as appearance/fit references. The unchanged source PNG and eight named SVG pose layers preserve each cell separately; `frames.json` records the seat/deck pivots. These are family-review candidates, not automatically approved artwork.

The original floor-sitting preview was rejected because the whole bicycle, including its saddle, drew in front of the body. The revised runtime assembles the frame, saddle and handlebars as parts behind the character. Bluey/Bingo use authored bike and scooter poses with explicit seat/deck pivots. Other characters and outfits currently retain their supported existing poses; their dedicated riding art remains future work. Hands/feet and left-facing animation need the actual-game preview review.

Exact prompt:

Create ONE transparent game sprite sheet, 4 columns by 2 rows, eight separated character-only drawings. Supporting reference 1 defines EXACT accepted Bluey face/body markings, reference 2 defines EXACT accepted Bingo; supporting reference 3 shows the vehicles they must fit. Preserve those characters' appearance and clean flat cartoon linework. Draw ONLY riders, NO bicycles, NO scooter, no seat, no pedals, no handlebars, no scenery, no text or grid lines. Every sprite wholly inside its equal square cell, consistent head/body scale and anchors per pair. Top row is Bluey in all four cells; bottom row Bingo in all four. All face RIGHT in a side view with recognizable face, not front view. Columns 1 and 2: genuine bicycle riding pose: torso slightly leaning forward, bottom clearly sitting on an imaginary saddle, both arms reaching forward toward handlebars, paws in grip pose at chest height; legs separately bent to two imaginary pedals BELOW the saddle. Col1 near leg down at 5 o'clock, far leg up at 11 o'clock; col2 swaps legs for gentle pedaling. Keep upper body/paws/seat contact in exactly same position in these two poses, head not bobbing. Columns 3 and 4: scooter poses, body standing and leaning slightly forward, both paws stretched forward gripping imaginary handlebar at lower-chest height; col3 both feet planted on imaginary horizontal low scooter deck, col4 near foot on that same deck and far leg stretched behind for a small kick. Keep deck-foot contact at identical coordinates in cols3/4, no bouncing head. Bike pose seat contact around 40% cell width and 67% cell height; paws around 83% cell width and 49% cell height; feet below seat near 85% cell height. Scooter planted deck feet around 45% cell width and 90% cell height, paws near 83% cell width and 47% cell height. Generous margins. Smooth alpha, no stray pixels. These are mechanically usable animation poses. Do not repeat the existing folded-leg floor-sitting pose. Wide 2:1 canvas overall.
