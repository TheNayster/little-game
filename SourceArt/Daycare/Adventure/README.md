# The Adventure kingdom artwork

The kingdom panorama was generated with the built-in image_gen tool on September 30, 2026. The exact prompt is in `kingdom-prompt.txt`. The original generated PNG is preserved here; the runtime copy is `Resources/Scenery/daycare-adventure.png`.

Characters reuse the prepared editable pose layers and runtime CharacterArt assets: Chloe, Coco, each Terrier, Winton, Honey, Rusty and Mackenzie. Crowns, bridge planks, the tennis ball, wand and prop highlights are editable runtime UI shapes. Picnic fruit reuses the kitchen ingredient atlas. Character model-sheet source layers remain in `SourceArt/Characters/ModelSheets`.

Generated artwork and voice lines are candidates for family review. No new character likeness or actor voice is claimed as approved. Original local storyteller recordings and exact generation settings are recorded in `SourceAudio/Adventure/manifest.json`.
